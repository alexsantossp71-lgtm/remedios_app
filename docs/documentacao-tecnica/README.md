# Documentação técnica

Esta pasta reúne a documentação técnica do projeto **Remédios na Hora**.

## Organização sugerida

À medida que os documentos forem criados, organize-os por assunto:

- **Arquitetura:** visão geral do sistema, componentes, serviços e fluxos.
- **Infraestrutura e deploy:** GitHub Pages, Cloudflare Worker, variáveis de ambiente e publicação.
- **Inteligência artificial:** provedores, modelos, roteamento, fallback, limites e diagnósticos.
- **Privacidade e segurança:** consentimento, tratamento de dados, armazenamento e controles.
- **Dados e integrações:** formatos, estruturas, APIs e integrações externas.
- **Manutenção:** procedimentos operacionais, solução de problemas e decisões técnicas.

## Convenções

- Registre a data, o escopo e a versão/commit relacionado quando aplicável.
- Diferencie comportamento implementado, comportamento testado e comportamento planejado.
- Não inclua chaves de API, tokens, senhas, dados pessoais ou informações reais de saúde.
- Ao documentar uma alteração, informe os arquivos afetados, a motivação, os testes realizados e eventuais limitações.
- Mantenha os documentos em Markdown (`.md`) sempre que possível.

## Índice

Os documentos técnicos serão adicionados aqui conforme forem produzidos.
